# FLove — Система лояльности для цветочного кафе

Полноценная система лояльности: Telegram-бот + FastAPI + SQLite + Web App.

## Возможности

- **Бот**: регистрация через Telegram (телефон → имя → фамилия → дата рождения), реферальные deep-link
- **Рассылки**: HTML-форматирование, фото, inline-кнопки, фильтры аудитории, превью
- **Карта клиента**: персональная карта с QR-кодом, бонусы, история, реферальная программа, контакты
- **Терминал кассира**: сканер QR камерой, начисление кэшбэка, списание бонусов, поиск по телефону
- **Админ-панель**: дашборд с KPI, управление клиентами, рассылки из веб-интерфейса, все транзакции
- **Реферальная система**: invite-ссылки, +5 р. рефереру, +3 р. новому клиенту
- **База данных**: SQLite (WAL) — пользователи, транзакции, рефералы, рассылки, настройки

## Архитектура

```
telegram-bot/
├── bot.py           # Telegram-бот (регистрация, рассылки, рефералы, команды)
├── server.py        # FastAPI-сервер (REST API + раздача webapp/)
├── database.py      # SQLite: users, transactions, referrals, broadcasts, settings
├── webapp/
│   ├── client.html    # Карта лояльности (QR, бонусы, рефералы, контакты)
│   ├── scanner.html   # Терминал кассира (сканер QR, начисление, списание)
│   └── admin.html     # Панель управления (дашборд, клиенты, рассылки, настройки)
├── requirements.txt
├── .env.example
└── DEPLOY.md          # Подробная инструкция развёртывания (Caddy + systemd)
```

## Быстрый старт

### 1. Установка

```bash
cd telegram-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка

```bash
cp .env.example .env
```

Заполните `.env`:
- `BOT_TOKEN` — токен от @BotFather
- `WEBAPP_URL` — HTTPS-адрес, по которому доступен сервер (например `https://your.dacdns.org`)

### 3. Запуск сервера

```bash
python server.py
```

### 4. Запуск бота

```bash
python bot.py
```

### 5. HTTPS

Для Telegram Web App нужен HTTPS:
- **Caddy** (рекомендуется): см. `DEPLOY.md`
- **ngrok** для теста: `ngrok http 8000`

## API

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/user/{telegram_id}` | Данные пользователя |
| GET | `/api/user/by-phone/{phone}` | Поиск по телефону |
| POST | `/api/purchase` | Покупка + кэшбэк |
| POST | `/api/redeem` | Списание бонусов |
| GET | `/api/user/{id}/history` | История транзакций |
| GET | `/api/user/{id}/referrals` | Рефералы пользователя |
| GET | `/api/referral/{code}` | Проверка реф. кода |
| GET | `/api/users` | Все пользователи (поиск, пагинация) |
| GET | `/api/admin/stats` | Статистика (KPI, уровни, топ клиенты) |
| GET | `/api/admin/transactions` | Все транзакции |
| POST | `/api/broadcast` | Создать рассылку |
| GET | `/api/broadcasts` | Список рассылок |
| POST | `/api/broadcast/{id}/send` | Отправить рассылку |
| PUT | `/api/user/role` | Изменить роль пользователя |
